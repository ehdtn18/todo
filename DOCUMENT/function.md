# 기능 명세 (function.md)

> 사용자가 설명한 기능을 기록하는 문서. (작성: Claude)
> 현재 구현된 기능은 `REFERENCE/index.html`을 이식한 것이며, 아래는 그 기능 목록이다.

## 1. 할 일(Task) 작성

- **제목**: 필수.
- **내용(블록 에디터)**: 필수. `/` 슬래시 명령으로 블록 추가.
  - 블록: 텍스트, 제목1~3, 글머리 목록(ul), 번호 목록(ol), 인용(quote), 구분선(hr).
  - 인라인 마크다운: `**굵게**`, `*기울임*`, `` `코드` ``, Ctrl/Cmd+B 굵게.
  - 저장 시 마크다운 문자열로 직렬화.
- **기간**: 필수. 시작일~마감일 범위 선택(달력 팝업). 한국 공휴일 표시.
- **우선순위**: 필수. 높음 / 중간 / 낮음.
- 누락 항목이 있으면 토스트로 안내하고 해당 필드 강조.

## 2. 뷰(View)

- **리스트**: 행(rows)형 / 카드(cards)형 전환. 카드형은 "내용 모두 보기/접기" 토글.
  - 필터: 전체 / 진행 중 / 완료 (개수 표시).
  - 정렬: 마감 임박순 / 등록순.
- **칸반**: 시작전 / 진행 중 / 완료 / Drop 4개 칼럼.
  - 시작전·진행중·Drop은 기간과 오늘 날짜로 **자동 분류**.
  - 카드를 완료 칸으로 드래그하면 완료 처리, 다른 칸으로 옮기면 완료 해제.
- **달력**: 월 단위. 여러 날에 걸친 일정을 가로 막대(레인 배치)로 표시.
  - 옵션: "평일만 보기", "완료 숨기기".
  - 한국 공휴일(2025~2027) 표시.

## 3. 수정 / 삭제

- 수정 모달: 상태(완료) 토글, 제목·내용·기간·우선순위 편집.
- 내용이 바뀌면 **수정 이력(history)** 에 이전 버전을 자동 저장.
- 삭제 시 확인 모달.

## 4. 수정 로그 / 롤백

- 수정 이력이 있으면 "수정됨 N회" 표시 및 로그 모달 열기.
- 로그 모달: 좌측 버전 목록, 우측 미리보기. 과거 버전으로 **롤백** 가능.

## 5. 통계 / 기타

- 진행률 링(완료율 %), 요약 문구.
- 백업 **내보내기**(JSON 다운로드) / **가져오기**(JSON 업로드, id 기준 추가·갱신).
- "완료 항목 비우기".

## 6. 저장 동작

- 모든 변경은 즉시 MySQL `tasks` 테이블에 반영(전체 배열 교체 방식).
- 뷰/레이아웃 환경설정은 브라우저 localStorage에 저장.

## 추가 기능 요청 (신규)

### 반응형 디자인 (2026-06-01)

- 모바일 · 태블릿 · PC 3개 디바이스 계층 모두 대응.
- 브레이크포인트:
  - **PC**: `> 1024px` — 기본 레이아웃(컨테이너 최대 1120px, 칸반 4열).
  - **태블릿**: `561px ~ 1024px` — 컨테이너 폭 100%, 칸반 2열, 카드 2열.
  - **모바일**: `≤ 560px` — 여백 축소, 작성 폼/컨트롤 세로 스택, 추가 버튼·우선순위·세그먼트 전폭, 모달 여백 축소.
  - **작은 모바일**: `≤ 400px` — 달력 막대 폰트/여백 축소로 가독성 확보.
- iOS 입력 자동 줌 방지를 위해 입력 글꼴 16px 유지.
- 디자인 톤(토스 스타일)은 그대로 유지하고 레이아웃만 적응.

### 달력 다중 주 hover 동기화 (2026-06-01)

- 여러 주에 걸친 할 일은 주별로 막대(`.cv-bar`)가 분리 렌더된다.
- 한 막대를 hover하면 **같은 할 일의 다른 주 막대도 함께 hover 상태**가 되도록 동기화.
- 구현: `data-id` 기준으로 `.cv-bar`에 `.hl` 클래스를 일괄 토글 (mouseover/mouseout 위임).

- 인터랙션 가능한 모든 요소에 hover/누름(press) 피드백과 전환 애니메이션 추가.
- 대상: 세그먼트 버튼, 우선순위 버튼, 기간 필드, 토글 스위치, 정렬/카드 토글, 모달 닫기(회전),

- 컴포저·컨트롤·헤더에 첫 진입 페이드업 애니메이션.
- `prefers-reduced-motion`에서는 전역 규칙으로 모두 비활성화(접근성 유지).

### 대규모 개선 요청 (2026-06-01) — 13건

1. **달력 다중 주 hover 동기화 강화**: 여러 주에 걸친 같은 할 일 막대를 hover 시 모든 주에서 함께 강조(시각적으로 확실하게).
2. **완료율 링 조정**: 퍼센트 숫자는 더 작게, 원형 그래프는 조금 더 크게.
3. **하단 버튼 제거**: 백업 내보내기/가져오기/완료 항목 비우기 삭제.
4. **칸반 카드 클릭 → 수정 모달 바로 열기**, 칸반 카드의 연필 아이콘 제거.
5. **달력 진행중 막대 색상**: 오늘이 시작~마감 사이면 연한 파란색으로 표시.
6. **토스트 위치**: 화면 정중앙 상단 고정.
7. **Notion식 마크다운 단축키**: `- `/`* ` 불릿, `1. ` 번호, `# `/`## `/`### ` 제목, `> ` 인용, `--- ` 구분선. 슬래시 메뉴에 각 단축키 표기.
8. **다크/라이트 모드 토글**: 화면 상단에 추가, 설정 유지.
9. **Next dev 뱃지 영구 비활성화** (`devIndicators:false` 유지, 절대 되돌리지 않음).
10. **시간 설정 기능**: 새 할 일 생성 시 날짜 선택 후 시작/마감 시간 선택. 기본값 시작 09:00·마감 18:00, 사용자 변경 가능.
11. **달력 일간/주간/월간 보기** 전환. 일간은 시간대 타임라인 형태로.
12. **초기화 버튼**: 추가 버튼 옆. 클릭 시 확인 모달로 한 번 더 물어봄.
13. **휴지통**: 삭제한 할 일이 모이는 `trash` 테이블 신설. 휴지통에서 삭제해야 영구 삭제(복원 가능).

14. **리스트 항목 순서 변경**: 제목 → 추가정보 → 내용 순서를 **제목 → 내용 → 추가정보**로.
15. **카드 자세히 보기 UX 변경**: 컨트롤의 "내용 모두 보기" 버튼 제거. 대신 카드 안의 "자세히 보기"를 누르면 모든 카드가 함께 열리고, "닫기"를 누르면 함께 닫힘.
16. **기간 선택 자동 정렬**: 마감일을 먼저, 시작일을 나중에 골라도 자동으로 시작일·마감일 정렬 (예: 6/12 → 6/4 선택 시 시작 6/4, 마감 6/12).
17. **완료 토글 시 정렬 고정**: 리스트에서 완료해도 순서가 바뀌지 않게(제자리 유지). 대신 달력처럼 "완료 숨기기" 토글 추가.

### 노션 전체 블록 추가 + 엔터 줄바꿈 (2026-06-01)

- 슬래시(`/`) 메뉴에 노션 블록 전체 추가: 텍스트, 제목1~4(#,##,###,####), 글머리(-), 번호(1.),
  할일 목록([]), 토글 목록(>), 콜아웃, 인용("), 표, 구분선(---), 이미지, 동영상, 코드, 파일.
- 단축키 재배치: **토글=`>`**, **인용=`"`** (노션 규칙). 제목4 `####`, 할일 `[]`, 코드 ```` ``` ````.
- 이미지/동영상/파일: **로컬 업로드(public/uploads, /api/upload) + URL 임베드 둘 다** 지원.
- 본문 엔터 동작: **엔터=새 줄(새 블록)**, Shift+엔터=블록 내 줄바꿈. 한글 IME에서도 동작하도록 beforeinput 사용.
- 표·토글 중첩은 contenteditable 한계로 기본형 구현(노션 완전 동일 아님).

## 알림 기능 기획 (v1, 2026-06-01 — 사용자 컨펌 대기)

- **목적**: 마감 시간이 다가오는 할 일을 사용자에게 알림.
- **할 일별 설정**: 생성/수정 폼에 "알림" 토글 + 리드타임 선택(정시 / 10분 전 / 30분 전 / 1시간 전 / 1일 전). 기본 OFF, 기본 리드 10분.
  - 데이터: `notify`(bool), `notifyLead`(분). DB 컬럼 `notify`, `notify_lead`.
- **알림 시점**: (마감일 `end` + 마감시간 `endTime`) − 리드타임. 완료된 할 일은 알림 안 함.
- **동작**:
  - 30초마다 현재 시각과 비교해 도래한 알림 발생. 같은 알림 중복 방지(localStorage `careid_notified`).
  - 너무 오래 지난 마감(12시간 초과)은 앱 켤 때 무더기로 울리지 않도록 제외.
  - **브라우저 알림**(Web Notifications API, 권한 허용 시) + **인앱 알림 센터**(헤더 종 아이콘).
  - 권한은 알림 토글 ON 또는 종 클릭 시 요청.
- **알림 센터**: 헤더 종 버튼 → 패널에 최근 알림 목록(제목/마감 정보/시각). 항목 클릭 → 해당 할 일 수정 모달. 안 읽은 개수 배지. "모두 지우기".
- **저장**: 알림 로그 localStorage `careid_notiflog`(최근 50개), 안읽음 여부 포함.

### 중첩 리스트 + 단축어 보강 (2026-06-02)

- 글머리/번호/할일 목록에서 **Tab 들여쓰기 / Shift+Tab 내어쓰기**로 중첩(노션·슬랙식). 빈 항목 Enter는 한 단계 내어쓰고, 0단계면 일반 텍스트로.
- 번호 목록은 단계별로 번호 재계산(1, 1-1 식). 들여쓰기 단계별 불릿(•/◦/▪).
- **이미 쓴 글 앞**에 `- `/`1. `/`[] `/`# ` 등을 넣어도 변환되도록 수정(접두어만 제거, 뒤 텍스트 유지).
- 저장은 들여쓰기(2칸=1단계) 마크다운, 미리보기는 중첩 `<ul>/<ol>` 렌더.

### (기획중) 중간컨펌 필드 — 사용자 컨펌 대기 (2026-06-02)

- 하나의 task를 1차/2차/…/n차 컨펌으로 쪼개는 **옵션 필드**.
- 달력: task는 막대 1개로 표시하되 그 안에 1차/2차/n차를 표시(여러 개로 쪼개지 않음).
- 설계 확정 후 구현 예정.

- (여기에 사용자가 새로 요청하는 기능을 계속 추가)
